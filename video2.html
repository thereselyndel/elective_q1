Video 2 | HTML Document Structure

This video explains how to link a CSS stylesheet to an HTML document. It demonstrates how the link element is used inside the head section of an HTML page to connect it to an external CSS file.

The lesson also shows how linking CSS allows you to style and customize the appearance of an HTML webpage without placing all the styling directly inside the HTML file.
